# Gabriel Handford

I build developer tools, agent infrastructure, and software for Apple platforms.

Currently at [Instacart](https://github.com/instacart). Previously at [Keybase](https://github.com/keybase) and [Yelp](https://github.com/Yelp). I work mostly in Swift, Rust, and Go, with a recurring interest in developer experience, security, and making complex systems feel simple.

## Current work

| Project | What it does |
